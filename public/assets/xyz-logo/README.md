# XYZ logo

Path-based SVGs (no font needed). The cuts are real transparency, so the mark works on any background. viewBox 550x260.

- `xyz-currentcolor.svg`: fill follows CSS `color`. Use this for the screensaver.
- `dark/`: for dark backgrounds (#111214). Cycle: green, cyan, magenta, red, yellow, orange, violet.
- `light/`: for light backgrounds (#FAFAF7). Cycle: green, cyan, magenta, red, orange, violet (no yellow; it can't reach readable contrast on light).
